## Description

This is a game made using Unity Game Engine. During my childhood, I was fascinated with programming and wondered how games are made. And after I started learning programming and learned about game engines, I decided to go with Unity and made some simple games. This is one of the games in which I have worked for the longest. It is a simple game where player has to catch eggs falling from above in a basket. The speed and complexity of the egg falling increases with time making the game challenging and fun. The game features colorful graphics and engaging sound effects to enhance the game experience. The language used in the game is Bengali making it more relatable for Bengali speaking audience.
