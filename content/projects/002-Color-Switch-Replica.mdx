## Description

This is an android mobile game made using Unity Game Engine. It is a simple game where player has to pass a certain color ball through a multi-color shape. The ball can only pass through if the side of the shape is the same color as the ball. Otherwise, it is GAME OVER. The game is a replica of the popular game "Color Switch".

- Unity Game Engine
