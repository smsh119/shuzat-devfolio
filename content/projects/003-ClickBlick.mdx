## Description

This is an android mobile game made using Unity Game Engine. In this game, boxes are instantiated from the center of the screen and moves towards the edge of the screen in random speed and direction. The player has to tap on the boxes before it reaches the edge of the screen. If boxes reach the edge, it is GAME OVER.

## Build with

- Unity Game Engine
- C# Programming Language
